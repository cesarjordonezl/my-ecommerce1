# 🛍️ Ecommerce Web

Aplicación web de comercio electrónico desarrollada como proyecto práctico de desarrollo web. Incluye un catálogo de productos con imágenes locales, navegación entre páginas y un carrito de compras.

## 🌐 Demo en vivo

[Ver Ecommerce publicado en Netlify](https://ecommerce1-cesarordonez.netlify.app/)

## ✨ Características

- Catálogo de productos con imágenes locales.
- Página de inicio con imagen de portada.
- Navegación entre las páginas del sitio.
- Carrito de compras con indicador de cantidad.
- Página de contacto.
- Organización de archivos HTML, CSS, JavaScript e imágenes.

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript
- Git y GitHub
- Netlify para el despliegue

## 📂 Estructura del proyecto

```text
my-ecommerce1/

│   │   └── products/

```

*La estructura anterior es orientativa; debe ajustarse al contenido real del repositorio.*

## 🚀 Ejecución local

1. Clona el repositorio:

   ```bash
   git clone https://github.com/cesarjordonezl/my-ecommerce1.git
   ```

2. Entra en la carpeta:

   ```bash
   cd my-ecommerce1
   ```

3. Abre `index.html` en un navegador o utiliza la extensión Live Server de Visual Studio Code.

## 🎯 Objetivo del proyecto

Practicar y aplicar conocimientos de desarrollo web, organización de archivos, manejo de imágenes locales, interacción con JavaScript y publicación de sitios web.
